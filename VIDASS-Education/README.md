# VIDASS Education

גרסת Python ו-Streamlit למערכת ניהול מוסדות חינוך.

## הרצה

```powershell
cd VIDASS-Education
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

הנתונים נשמרים מקומית בקובץ `vidass_education.db` באמצעות SQLite.

חשבון חברת VIDASS לפיתוח מקומי: מזהה `admin`, סיסמה `admin`.
